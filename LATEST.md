## Updated for BTD6 v56

Opening **Settings → Player Data** showed the game's own Content Browser instead of the mod menu.

v56 removed the first/last page buttons from the content browser that this mod builds its menu on top of, so setting the menu up failed before it could replace any of the vanilla UI — leaving the browser underneath on screen. Page navigation now uses the previous/next buttons only, matching v56's layout.

**Requires BTD6 v56.**
